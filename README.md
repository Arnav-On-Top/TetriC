A Tetris game using C programming. User can first signup and then login to play. Players can select 3 modes, Easy with slow speed, Medium with moderate speed and Hard with faster speed. download the file in the release and run in terminal to run. If code is compiled in the user's personal IDE then it will create the login data files and score files too when the game is run.

Built as a project for Hack Club's Cresent YSWS [You Ship We Ship] Program under the category Wildcard
